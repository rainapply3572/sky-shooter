# 星河彈幕

直向像素彈幕射擊。戰機很小，真正會受傷的只有機體中央那一顆光點。敵機會射出差一點就擦到你的彈幕；打掉它們可以拿經驗，升級時從三個強化裡挑一個。

這款遊戲整體偏難。簡單只是比較疏，不是輕鬆模式；困難則是高速、高密度、敵機也更耐打。

## 怎麼玩

1. 用瀏覽器打開 `index.html`（建議透過本機伺服器或 GitHub Pages，不要直接用檔案總管點開）。
2. 按「開始任務」，選擇難度：簡單、中等或困難。
3. 倒數結束後會自動射擊。你要做的是走位。
4. 擊破敵機會掉綠色經驗球。經驗條滿了，遊戲會暫停，出現三張強化卡，選一張。
5. 撐過三個戰區，並打倒每一區最後的大型機體。
6. 你有 3 條命（陣亡後可以復活 2 次）。復活後有一小段無敵時間。第 3 次被擊中就任務失敗。

擦過彈幕（光點沒碰到、但很近）會加一點分數，畫面上會跳「擦彈」。

## 操作

### 電腦

- 方向鍵或 `W` `A` `S` `D`：移動
- 按住 `Shift`：低速，方便微調走位
- 滑鼠在遊戲畫面裡移動：戰機會跟著走，游標在機體稍下方
- `P` 或 `Esc`：暫停
- 升級畫面也可以按 `1`、`2`、`3` 選卡
- 射擊是全自動的

### 手機／平板（直向）

- 用手指按住畫面拖曳。手指若離戰機太近，戰機會先移到手指上方，避免手指擋住機體。
- 之後戰機跟著手指移動，並維持在手指上方。
- 放開手指後，戰機留在原地，繼續自動射擊。
- 右下角「低速」按住不放可以減速。
- 右上角可以暫停，或把音效關掉。
- 升級卡和選單都可以直接點。

頁面已禁止滑動與雙指放大，避免玩的時候整頁跟著跑。

## 武器與強化

一開始帶著「擴散彈」。升級時可能抽到新武器或舊武器的下一級，每一種最多 5 級，可以同時裝備。

| 武器 | 效果 |
| --- | --- |
| 擴散彈 | 向前方射出扇形彈。高等級會變密，第 5 級可以貫穿 1 架敵機。 |
| 貫穿雷射 | 一直線的雷射，打穿航道上的所有敵人。要自己對準。 |
| 追蹤飛彈 | 會轉彎追敵機。第 5 級命中時有小範圍爆炸。 |
| 穿透波動 | 緩慢、很寬、會貫穿的能量波。 |

其他常見強化：火力、射速、移動速度、浮游砲（最多 2 座，會自己瞄準）、能量護盾（最多同時 3 層，每層擋一次傷害）、吸收磁場（經驗球從更遠的地方飛過來）、緊急修復（補 1 條命）。

## 分數

每個難度各自記住最高分，存在這台裝置的瀏覽器裡（`localStorage`）。換電腦或清除網站資料後，紀錄會消失。

## 在自己的電腦試玩

在專案資料夾執行：

```bash
python3 -m http.server 8080
```

然後用瀏覽器打開 [http://localhost:8080](http://localhost:8080)。手機若和電腦在同一個 Wi-Fi，可以用電腦的區網位址加上 `:8080` 來玩。

## 用 GitHub Pages 公開

這個遊戲是純靜態網頁，不需要建置。`index.html` 就在儲存庫根目錄。

1. 把這個專案推上 GitHub，分支用 `main`。
2. 打開該儲存庫的 **Settings**。
3. 左側選 **Pages**。
4. 在 **Build and deployment** 的 **Source** 選擇 **Deploy from a branch**。
5. **Branch** 選 `main`，資料夾選 **`/ (root)`**，按 **Save**。
6. 等一兩分鐘，頁面上方會出現網址，形式像 `https://<你的帳號>.github.io/<儲存庫名稱>/`。
7. 用手機或電腦打開那個網址即可。若還是舊畫面，重新整理一次。

音效用瀏覽器的 WebAudio 現做，沒有外部音檔。第一次按按鈕後才會出聲，這是瀏覽器的規定。

## 想自己調難度

打開 `js/game.js`，最上面的 `DIFFS` 可以調彈速（`bulletSpeed`）、彈數（`density`）、敵機耐久（`hp`）和出現間隔（`spawn`，數字越小越密）。敵機血量在 `ENEMY_STATS`，頭目在 `BOSS_DEFS`。
