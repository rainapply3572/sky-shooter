# 星河彈幕

直向像素彈幕射擊。戰機很小，真正會受傷的只有機體中央那一顆光點。敵機的彈幕是帶黑邊的方塊；經驗是會閃、會轉的金色星星結晶，兩者不會搞混。升級時從三張卡裡挑一張。

這款遊戲整體偏難。簡單只是比較疏，不是輕鬆模式；困難則是高速、高密度、敵機也更耐打。

## 怎麼玩

1. 用瀏覽器打開 `index.html`（建議透過本機伺服器或 GitHub Pages，不要直接用檔案總管點開）。
2. 按「開始任務」，選擇難度：簡單、中等或困難。
3. 倒數結束後會自動射擊。你要做的是走位。
4. 擊破敵機會掉金色經驗結晶。經驗條滿了，遊戲會暫停，出現三張強化卡（普通、稀有、史詩、傳說），選一張。
5. 一路打過九個戰區。每一區的背景、敵機和頭目都不一樣，中間還有流星、雷擊、熔岩柱、賞金關和生存關。
6. 你有 3 條命（陣亡後可以復活 2 次）。復活後有一小段無敵時間。第 3 次被擊中就任務失敗。
7. 炸彈可以清掉畫面上的彈幕，並重創敵機。數量有限，打精英或撿道具可以再拿到。

擦過彈幕（光點沒碰到、但很近）會加一點分數，畫面上會跳「擦彈」。

## 操作

### 電腦

- 方向鍵或 `W` `A` `S` `D`：移動
- 按住 `Shift`：低速，方便微調走位
- 滑鼠在遊戲畫面裡移動：戰機會跟著走，游標在機體稍下方
- `P` 或 `Esc`：暫停
- `X` 或 `Z`：使用一顆炸彈
- 升級畫面也可以按 `1`、`2`、`3` 選卡
- 射擊是全自動的

### 手機／平板（直向）

- 用手指按住畫面拖曳。手指若離戰機太近，戰機會先移到手指上方，避免手指擋住機體。
- 之後戰機跟著手指移動，並維持在手指上方。
- 放開手指後，戰機留在原地，繼續自動射擊。
- 右下角「低速」按住不放可以減速。再上面的「炸」是炸彈。
- 右上角可以暫停，或把音效關掉。
- 升級卡和選單都可以直接點。

頁面已禁止滑動與雙指放大，避免玩的時候整頁跟著跑。

## 武器與強化

一開始帶著「擴散彈」。升級時可能抽到新武器，或讓舊武器換成另一種射法（不是只加數字）。每一種最多 5 級，可以同時裝備。滿級再配上對應的被動，會出現「傳說」進化。

| 武器 | 等級會改變的事情 | 進化 |
| --- | --- | --- |
| 擴散彈 | 變寬、加尾彈、中央貫穿、左右鎖定 | 星爆彈：每次射擊多炸一圈 |
| 貫穿雷射 | 變粗、兩側火花、脈衝、雙光束 | 折光雷：折出追蹤副光束 |
| 追蹤飛彈 | 雙發、轉更快、三發、命中爆炸 | 蜂群飛彈：分裂成一小群 |
| 穿透波動 | 變大、雙波、途中爆火花、三道大波 | 引力波：把經驗結晶吸過來 |
| 環刃 | 刃數、外噴小彈、追向附近敵機 | 劍陣：更快、更大圈 |
| 穿甲彈 | 變快、命中爆炸、雙發、留下軌跡 | 殲滅砲：更長的毀滅軌跡 |

其他強化分稀有度：火力、射速、移速是普通；護盾、磁場、浮游砲、經驗增幅、炸彈補給是稀有；暴擊、殘影迴避、緊急修復和高等級武器是史詩。

## 九個戰區

外環塵域、流星帶（隕石）、月蝕星環、雷雲走廊（落雷）、熔核航道（障礙柱與熔岩）、賞金航道、虛空深境、蟲巢深淵（生存波）、終焉星門。有些區中途會先出精英。

## 分數

每個難度各自記住最高分，存在這台裝置的瀏覽器裡（`localStorage`）。換電腦或清除網站資料後，紀錄會消失。

## 在自己的電腦試玩

在專案資料夾執行：

```bash
python3 -m http.server 8080
```

然後用瀏覽器打開 [http://localhost:8080](http://localhost:8080)。手機若和電腦在同一個 Wi-Fi，可以用電腦的區網位址加上 `:8080` 來玩。

## 用 GitHub Pages 公開

這個遊戲是純靜態網頁，不需要建置。`index.html` 就在儲存庫根目錄。

1. 把這個專案推上 GitHub，分支用 `main`。
2. 打開該儲存庫的 **Settings**。
3. 左側選 **Pages**。
4. 在 **Build and deployment** 的 **Source** 選擇 **Deploy from a branch**。
5. **Branch** 選 `main`，資料夾選 **`/ (root)`**，按 **Save**。
6. 等一兩分鐘，頁面上方會出現網址，形式像 `https://<你的帳號>.github.io/<儲存庫名稱>/`。
7. 用手機或電腦打開那個網址即可。若還是舊畫面，重新整理一次。

音效用瀏覽器的 WebAudio 現做，沒有外部音檔。第一次按按鈕後才會出聲，這是瀏覽器的規定。

## 想自己調難度

打開 `js/game.js`，最上面的 `DIFFS` 可以調彈速（`bulletSpeed`）、彈數（`density`）、敵機耐久（`hp`）和出現間隔（`spawn`，數字越小越密）。敵機血量在 `ENEMY_STATS`，頭目在 `BOSS_DEFS`。
